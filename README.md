# CVFlash — CV et lettre de motivation gratuits (PDF)

[**Utiliser CVFlash gratuitement**](https://cvflash-gratuit.vercel.app)

CVFlash est un mini-outil gratuit et accessible sans inscription. Il permet de créer un CV professionnel clair en français, de personnaliser ses expériences et compétences et d'exporter le résultat en PDF grâce à la fonction d'impression du navigateur.

**Outils disponibles :**
- [Générateur de CV gratuit](https://cvflash-gratuit.vercel.app/)
- [Lettre de motivation gratuite (CDI, CDD, alternance, job étudiant)](https://cvflash-gratuit.vercel.app/lettre.html)
- [3 exemples de lettres pour débutants et candidats sans expérience](https://cvflash-gratuit.vercel.app/exemples.html)

## Données personnelles
Les informations saisies dans le générateur de CV sont conservées localement dans le navigateur, sans serveur. Le bouton « Effacer mes données » supprime le brouillon sur l'appareil.

## Fonctionnement
Projet statique HTML/CSS/JavaScript, sans service payant ni inscription. Les fichiers sont dans le dossier [cvflash](./cvflash).

## Soutien facultatif
Les outils sont gratuits. Un lien de contribution PayPal volontaire figure sur le site. Aucune contribution n'est requise pour utiliser les outils.
